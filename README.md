# 東京ディズニーシー 3D園内マップ（非公式）

東京ディズニーシーの園内を、OpenStreetMap の実データから作った3D模型で見渡し、アトラクション・レストラン・ショップ・トイレまでの最短経路を一人称（POV）で歩いて確認できる静的Webページです。
新宿駅乗り換え3D（[Shinjuku](https://github.com/devworks12/Shinjuku)）と同じ作り方の、テーマパーク版です。

- 地図データ: © OpenStreetMap contributors（ODbL）
- 建物の形・高さ・色、経路と所要時間は、地図データからの推定を含む「模型」です。

## できること
- **出発地・目的地を選ぶと、その場で最短経路をプレビュー**。「歩いてみる ▶」で POV 再生（標準・高速・超高速）
  - 一覧は種類別（入口・アトラクション・ショー・レストラン/フード・ショップ・トイレ・サービス）。名前・エリア名・ひらがなで検索できる
  - ルート1（最短）・ベビーカー/車いす（階段を避ける）・ルート2〜3（別の通路）。経由エリア・階段の有無・距離・徒歩の目安
  - 道順: 「◆ アメリカンウォーターフロントに入る」「≋ ○○（橋）を渡る」「↱ 右へ曲がる（○○のあたり）」など
- **最寄りのトイレ・フード・ショップ**を、出発地（または 📍 現在地）から歩く時間で探す
- **地図の上のピン**（カテゴリごとに表示を切り替え）。タップすると「ここから出発 / ここへ行く」
- **📍 現在地**（GPS）を出発地にできる（園内にいるとき）
- **🌙 夜**: 窓・街灯・火口が光る夜景
- 3D模型: 8つのテーマポート＋エントランスごとの街並み（壁の色・窓・屋根の形・舗装・木の種類）、水面の映り込み、岩山（ロックワーク）、高架のエレクトリックレールウェイ、橋のアーチ、街灯、ランドマーク（プロメテウス火山・ホテルの塔・蒸気船・地球儀の噴水・灯台・城・神殿・要塞・宮殿・帆船）
- POV: 案内カード、進捗バー、回るミニマップ。タップで一時停止、左右スワイプで戻す/進める、上下スワイプで見上げる
- 操作は地図アプリと同じ（`js/nav.js`）。URL（`#出発>到着`）で経路を共有

## 構成
```
index.html / css/style.css      画面
js/app.js                       three.js の描画・カメラ・ピン・UI・POV・ミニマップ
js/model.js                     模型の組み立て（地面・水面・岩・建物・通路・木・街灯）
js/landmarks.js                 ランドマーク（火山・塔・船・城など）の手続き的な模型
js/textures.js                  canvas で描くテクスチャ（石畳・芝・壁の窓・水面のさざ波）
js/route.js                     経路探索（ダイクストラ・ルート候補）と案内文（three.js 非依存）
data/park.json                  tools/build_park.py が作る園内データ
data/raw/                       OSM 生データ（Geofabrik 関東抽出から切り出し）
tools/build_park.py             OSM → park.json 変換（標準ライブラリのみ）
tools/park_config.py            エリア・アトラクション名・建物の高さ・ランドマークの手動設定
tools/test/routes.mjs           経路テスト（node tools/test/routes.mjs [出発] [到着]）
.github/workflows/fetch-osm.yml OSM データ取得と park.json 再生成（手動 / 毎月）
```

## データの作り方
1. GitHub Actions「Update park data」が Geofabrik の関東抽出から東京ディズニーシー周辺を `osmium` で切り出し、`data/raw/` に保存、`park.json` を作り直してコミットします（Actions タブから手動実行、または毎月1日に自動）。
2. 手元で作り直す場合は `python3 tools/build_park.py --report`。

変換のポイント:
- 園の外周（`tourism=theme_park`）の中の面を、水面・岩・砂・林・植栽・広場・駐車場・建物に分ける
- 建物の高さは `height` / `building:levels` タグ、無ければ `park_config.py` の値、それも無ければ面積とエリアから推定
- エリア（テーマポート）は、`park_config.py` の目印（各エリアの施設名）にいちばん近いものへ振り分け
- 歩行グラフ: `footway / pedestrian / steps / path` の線をつなぎ、広場（`highway=pedestrian` の面）の中は見通せる点どうしを直線でつなぐ（建物・水面を横切る線は作らない）
- 施設は、建物の中にあれば建物の出入口（`entrance=*`）のそばの通路へ、無ければ建物・水面を横切らずに届く一番近い通路へつなぐ
- アトラクション・ショーは正式名称に、名前の無いトイレ・ワゴンには近くの施設名を添える

## ローカルで見る
```
python3 -m http.server 8000
# → http://localhost:8000/
```
（three.js とフォントは CDN から読み込みます）
